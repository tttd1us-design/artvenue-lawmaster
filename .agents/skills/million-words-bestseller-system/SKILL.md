## 🎨 3. 을유문화사 『이기적 유전자』 스타일 B5 클래식 조판 규격

### 3-1. 타이포그래피 및 컬러 시스템
* **용지 규격:** 신국판 B5 (182mm × 257mm) / 상24, 하22, 좌20, 우20mm 마진.
* **배경 및 본문 톤:** 앤티크 미색 서적지(`#FAF8F5`), 웜 차콜(`#2A3439`), 옥스퍼드 버건디(`#6B1D2F`), 앤티크 골드(`#C2882A`).
* **행간 및 들여쓰기:** 황금 비율 행간 `1.75~1.88`, 본문 문단 첫 줄 1자 들여쓰기(`first_line_indent = Pt(10.5)`), 챕터별 첫 글자 드롭캡(Drop Cap).

### 3-2. 풀 블리드(Full Bleed) 1페이지 표지 조판 기법
* **표지 반복 오류 원천 차단:** 브라우저 인쇄 엔진에서 `position: fixed`를 사용할 경우 모든 페이지에 표지가 배경으로 중복 출력되는 치명적 버그가 발생함.
* **해결 원칙:** 
  1. 본문 HTML 내 표지는 인쇄 시 숨김(`@media print { .book-cover-page { display: none !important; } }`).
  2. 표지는 `part0_cover.html`을 통해 **182mm × 257mm 무마진 1페이지 단독 PDF(`part0_cover.pdf`)**로 생성.
  3. 최종 머지 시 맨 첫 1페이지로 무손실 결합.

## ⚙️ 4. 1,000+ 페이지 무손실 벡터 PDF 분할 & 결합 파이프라인

단일 대용량 HTML(2.2MB+, 297개 파일)을 한 번에 브라우저에서 인쇄할 경우 메모리 한계로 중간(예: p.513)에서 잘리는 현상이 발생합니다.

### 4-1. 7단계 분할 렌더링 & 결합 알고리즘
```python
import fitz  # PyMuPDF

# 1. 파트별 개별 PDF 생성 (각 100~250페이지)
parts = [
    ("part0_cover", [cover_item]),
    ("part1_frontmatter", frontmatter_items),
    ("part2_vol1", vol1_items),
    ("part3_vol2", vol2_items),
    ("part4_vol3", vol3_items),
    ("part5_vol4", vol4_items),
    ("part6_vol5", vol5_items),
    ("part7_backmatter", backmatter_items),
]

# 2. PyMuPDF 무손실 벡터 결합
merged_doc = fitz.open()
for slug, _ in parts:
    part_doc = fitz.open(f"{slug}.pdf")
    merged_doc.insert_pdf(part_doc)
    part_doc.close()

merged_doc.save("complete_book_master.pdf")
```

## 📝 5. Word (DOCX) 출판사 납품 규격 및 무결성 보장

1. **`keep_with_next = True` 의무 적용:** 모든 Heading(H1, H2, H3, H4) 및 테이블 캡션에 `p.paragraph_format.keep_with_next = True`를 적용하여 페이지 하단 제목 고립(Orphan Title) 원천 차단.
2. **의무 자동 백업본 동시 생성:** 문서 생성 즉시 동일 디렉터리에 `_BACKUP.docx` 파일을 자동 복사 저장.
3. **1페이지 전폭 표지 이미지 삽입:** B5 전폭(폭 142mm / 5.59인치)에 맞춰 표지 이미지를 첫 장에 배치.
