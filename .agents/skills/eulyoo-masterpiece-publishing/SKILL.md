# Eulyoo Masterpiece Publishing System (을유문화사 클래식 에디션 마스터 출판 스킬)

이 스킬은 을유문화사의 명저 **『이기적 유전자』**와 같은 고품격 클래식 인문·교양과학 단행본의 장정(裝幀)과 조판 양식을 대한민국 모든 도서 집필의 **'공식 기준 포맷(Canonical Standard Format)'**으로 정립하여, 100만 자 규모의 방대한 도서를 단 한 줄의 요약이나 글리치 없이 최고급 양장본 규격으로 완전 집필·조판·출판하는 마스터 시스템입니다.

---

## 1. 🏛️ 표지 디자인 표준 (1-Page Dedicated Classic Cover)

을유문화사 특유의 따뜻하고 지적인 미색 서적지(Ivory Linen) 배경과 절제된 3색 컬러 시스템을 엄격히 적용합니다.

```
[을유문화사 클래식 표지 4대 구성 원칙]
1. 바탕 컬러: 따뜻한 앤티크 린넨 / 미색 아이보리 (#FAF8F5 ~ #F8FAFC)
2. 컬러 시스템 (3-Tone Restraint):
   - Main: Deep Charcoal Navy (#0B1120 또는 #1A1A1A)
   - Sub: Oxford Burgundy (#6B1D2F) 또는 Royal Cobalt (#1E40AF)
   - Point: Antique Matte Gold (#C2882A / #B45309)
3. 타이포그래피:
   - 국문 대제목: 묵직하고 단정한 전통 명조체 (24~26pt, 장식 배제)
   - 영문 부제: Baskerville / Garamond / Trajan 계열의 클래식 로만 세리프
4. 띠지 (Obi Band):
   - 슬레이트 네이비 & 샴페인 골드 액센트로 교보문고·예스24 종합 1위 추천 문구 일체형 탑재.
   - 인쇄 및 PDF 출력 시 정확히 1페이지만 점유하도록 page-break-after: always; 격리.
```

## 2. 📐 판형 및 황금 여백 규격 (Golden Margin System)

책을 손에 쥐었을 때 엄지손가락이 텍스트를 가리지 않고, 두꺼운 제본에서도 글자가 안쪽으로 말려 들어가지 않도록 설계된 인문학 황금 마진입니다.

* **표준 판형**: **신국판 (152mm × 225mm)** 또는 **B5 변형판 (182mm × 257mm)**
* **황금 여백 (Margins)**:
  * **상단 (Top Margin)**: `25.0mm` (러닝 헤더 / 기둥 표제 영역)
  * **하단 (Bottom Margin)**: `22.0mm` (정갈한 페이지 넘버링)
  * **안쪽 / 제본 (Gutter / Inside)**: `22.0mm` (중앙 몰림 방지)
  * **바깥쪽 (Outside Margin)**: `20.0mm` (시각적 여유 공간)

## 3. ✍️ 내지 타이포그래피 & 조판 규칙 (Interior Typography)

| 항목 | 표준 조판 사양 | 실무 가이드라인 |
| :--- | :--- | :--- |
| **본문 서체** | • KoPub World 바탕체 / Noto Serif KR (400 Regular) | 한글 가독성이 가장 뛰어난 정통 인문 명조 |
| **제목 서체** | • Pretendard Bold / KoPub 바탕 Bold | 묵직하고 단정한 고딕-명조 조화 |
| **본문 크기 & 행간** | • 글자 크기: **10.2pt**<br>• 행간: **1.92 (192%)** | 800페이지 이상에서도 눈의 피로도 제로화 |
| **문단 정렬** | • 양쪽 맞춤 (Justified)<br>• 문단 첫머리 **1em(1글자) 들여쓰기** | 문단 간 빈 줄을 넣지 않는 정통 단행본 양식 |
| **러닝 헤더** | • 좌측 상단: [도서명 또는 부(PART)]<br>• 우측 상단: [현재 장(Chapter) 제목] | 8.5pt Noto Serif KR + 얇은 0.5pt 가이드라인 |
| **인용문 (Blockquote)** | • 좌측 4px 샴페인 골드 라인 (#C2882A)<br>• 좌우 1.5em 인셋 + 9.5pt 이탤릭 명조 | 중요한 핵심 테제와 명언 강조 |
| **표 (Table)** | • 상하 2.0px 다크 슬레이트 보더 (#0B1120)<br>• 헤더: 딥 네이비 배경 (#0B1120) + 화이트 텍스트 | 가로 스크롤바와 터미널 글리치 원천 차단 |

## 4. 📖 5단계 챕터 아키텍처 (Chapter Framework)

모든 챕터는 다음의 통일된 리듬으로 서술되어 독자에게 깊은 지적 통찰과 실천적 지혜를 제공합니다.

```
[CHAPTER HERO BADGE: PART X | CHAPTER XX]
# 제XX장 | [장 제목] — [부제]
> **[핵심 테제 (Core Thesis)]**: 불변의 진리와 원리를 1~2문장으로 압축 선언.

---

### 1. [오프닝 씬 (Malcolm Gladwell Scene)]
역사적 D-Day 현장의 영화적 복원과 통념을 뒤엎는 역설적 질문(Paradoxical Question) 제기.

### 2. [원리와 메커니즘 (Daniel Kahneman & First Principles)]
행동경제학, 인지 편향 해체, 정밀한 수학적/통계적 모델 및 실증 데이터 제시.

### 3. [빅테크 및 실전 사례 (Empirical Case Studies)]
국내 선도 기업의 성공/실패 사례 vs 글로벌 최상위 벤치마크 심층 대조.

### 4. [맹점과 한계 분석 (Critical Analysis & Human-in-the-Loop)]
AI의 할루시네이션, 예측 불가능한 거시적 리스크, 인간 전문가의 비판적 검증 프로토콜.

### 5. [달리오의 실전 원칙 및 인생 적용 (Ray Dalio Principles & Life Wisdom)]
[원칙 #1] ~ [원칙 #5] 넘버링된 실천 지침 및 개인의 삶과 자산에 적용하는 지혜.

### 6. [저자의 시선 (Author's Column)]
20년 현장 경험에서 우러나온 고뇌와 결단의 철학적 에세이.

### 7. [클로징 및 다음 장 연결 (Summary & Next Step)]
3대 핵심 요약 불릿 + 다음 장으로의 자연스러운 내비게이션.
```

## 5. 📚 권위 있는 부속 편람 구성 (Back Matter Standards)

도서의 신뢰도와 학술적 가치를 결정짓는 부록 6대 편람 표준:

1. **부록 A (플랫폼/도구 디렉토리)**: 150+ 핵심 플랫폼 기능·가격·활용법 총망라.
2. **부록 B (개념 용어 사전)**: 200대 핵심 전문 용어 알파벳/가나다순 완전 해설.
3. **부록 C (공공데이터 및 API 가이드)**: 국가 공적 데이터 원천 연동 프로토콜.
4. **부록 D (실무 체크리스트)**: 전 단계별 100대 실무 점검표.
5. **부록 E (참고문헌 및 출처)**: 국내외 120여 편 공적 리포트 및 학술 논문 목록.
6. **부록 F (찾아보기 / 색인)**: 주요 인명, 기업명, 기술 용어 페이지 인덱스.

## 6. 🚀 다중 포맷 자동 빌드 파이프라인 (Execution Rules)

* **PDF 빌드**: Microsoft Edge Headless 엔진(`--headless --disable-gpu --no-pdf-header-footer --print-to-pdf`)을 활용하여 B5 신국판 초고화질 벡터 인쇄본 생성.
* **Word (DOCX) 빌드**: `python-docx` 라이브러리를 통해 B5 마진 설정, 비-XML 제어문자 정제(`re.sub(r'[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]', '', text)`), 1페이지 표지 및 목차 자동화.
* **HTML 빌드**: 반응형 인터랙티브 E-Book 뷰어 및 점선 리더(Dot Leader) 스무스 스크롤 목차 탑재.
* **Markdown 빌드**: 전체 원고 아카이빙용 무결점 통합본 출력.
